# סטודיו שיווק נכסים

אפליקציית דפדפן לבניית **מצגת מכירה לבעלי נכס** (מוכרים ומשכירים): שאלון נכס, ניתוח שוק השוואתי (CMA) עם נתוני הלמ״ס, תכנית שיווק של עד 180 יום, גרפיקות, פוסטים והודעות וואטסאפ — והכול נאסף למצגת שמוכנה להצגה ולשמירה כ-PDF.

## הפעלה

```bash
cd marketing-app
node server.js        # http://localhost:8080
```

השרת מגיש את האפליקציה ומשמש כפרוקסי ל-API של הלמ״ס (וכמה מקורות ממשלתיים נוספים ברשימת היתרים), כדי שהדפדפן לא ייחסם בגלל CORS. אפשר גם לפתוח את `index.html` ישירות. כל השאר עובד, אבל ייתכן ששאיבת הנתונים מהלמ״ס תיחסם, ואז מדביקים את המדד ידנית.

אין תלויות ואין שלב build. הנתונים נשמרים ב-`localStorage` של הדפדפן. בלשונית ״הגדרות״ יש ייצוא ושחזור של גיבוי JSON.

| **גרפיקות** | 8 תבניות (תמונה מלאה, פאנל, מסגרת, קולאז׳, אינפוגרפיקה, בית פתוח, עדכון מחיר, נמכר) ב-4 פורמטים (פוסט, 4:5, סטורי, באנר), עם לוגו ופרטי הסוכן. הורדה כ-PNG |

| **מצגת** | עד 17 שקפים: שער, מי אנחנו, הנכס, מיצוב וקהל יעד, גלריה, מגמות שוק, עסקאות להשוואה, הערכת שווי, אסטרטגיית מחיר, ״למה תמחור נכון קריטי״, ערוצים, דוגמאות גרפיקה, תכנית, לוח אירועים, דיווח, סינון שוכרים (בהשכרה) והשלבים הבאים עם שורות חתימה. כולל מצב הצגה במסך מלא והדפסה ל-PDF |

## מקורות נתונים, ומה חשוב לדעת

- **הלמ״ס**: ה-API הציבורי של המדדים (`/index/data/price`). קוד ברירת המחדל הוא `40010` (מדד מחירי דירות). את הקוד של מדד שכר הדירה מזינים בהגדרות.
- **עסקאות נדל״ן (GovMap / רשות המסים)**: הנתונים נשאבים מ-`www.govmap.gov.il/api/real-estate/*`. השרת המקומי (`/api/deals?address=…&years=2&radius=100`) מבצע את כל השלבים: איתור הכתובת, מציאת החלקות הסמוכות, ושליפת עסקאות ברמת הרחוב והשכונה. כשהאפליקציה רצה בלי השרת, היא מנסה לפנות ישירות מהדפדפן. ה-API אינו מתועד רשמית ועלול להשתנות. נשארו גם הדבקה וייבוא קובץ כגיבוי.
- המאגר כולל עסקאות **מכירה** בלבד. לשכירות משתמשים בהזנה ידנית או בייבוא.
- הערכת השווי היא ניתוח שוק לצורכי שיווק, **ולא שומת מקרקעין**.
