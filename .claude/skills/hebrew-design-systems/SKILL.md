# Hebrew Design Systems (skills-il/design-systems)

Each folder under `systems/<slug>/` holds:
- `DESIGN.md` — the full design system (single source of truth). Read it fully before applying.
- `metadata.json` — name, tagline, mood, fonts.

## How to use
1. Match the brief's mood/audience to a system using the table below (read `metadata.json` when unsure).
2. Read that system's `DESIGN.md` and follow its tokens, type scale and RTL/localization rules exactly.
3. When the user wants to adopt one permanently, copy its `DESIGN.md` to the project root.
