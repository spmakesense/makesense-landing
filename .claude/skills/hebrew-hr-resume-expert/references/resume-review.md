# אבחון ובניית קורות חיים

## מבנה מומלץ (לפי סדר)

1. **פרטי קשר** — שם (גדול), תפקיד יעד בשורה אחת מתחת, טלפון | מייל | לינקדאין | עיר | (GitHub/תיק עבודות אם רלוונטי)
2. **תקציר מקצועי** — 2–4 שורות: מי אני + כמה שנים + במה אני הכי חזק/ה + הישג/ערך מרכזי
3. **ניסיון תעסוקתי** — כרונולוגי הפוך, 3–6 שורות לתפקיד אחרון, פחות לישנים
4. **השכלה** — תואר, מוסד, שנה (ציון רק אם 85+ / מצטיינים)
5. **שירות צבאי / לאומי** — כשהוא רלוונטי או בתחילת קריירה (ראו `israeli-market.md`)
6. **כישורים** — טכניים / כלים / שפות (עברית — שפת אם, אנגלית — רמה גבוהה מאוד וכו')
7. **אופציונלי** — הסמכות, התנדבות, פרויקטים, פרסומים

**בוגרים טריים / מתחילים:** השכלה + צבא + פרויקטים לפני ניסיון.
**10+ שנים:** תקציר חזק + "הישגים נבחרים" בראש, ניסיון לפני 15 שנה בשורה מקוצרת או בכלל לא.

## תקציר — נוסחה

`[תפקיד/זהות מקצועית] עם [X] שנות ניסיון ב[תחום]. מתמחה ב[2–3 חוזקות]. [הישג מספרי בולט]. מחפש/ת [סוג תפקיד/ערך שאביא].`

> ✗ "אדם חרוץ, אחראי ובעל יחסי אנוש מעולים, מחפש אתגר חדש."
> ✓ "מנהלת שיווק דיגיטלי עם 7 שנות ניסיון ב-B2B SaaS. הובלתי קמפיינים שהגדילו לידים ב-140% בשנה בתקציב קבוע. מתמחה ב-Performance, אוטומציה ו-ABM."

## בניית קו"ח מאפס — סדר שאלות (אחת בכל פעם)

1. לאיזה תפקיד/תחום את/ה מכוון/ת?
2. מה התפקיד הנוכחי/אחרון? חברה, תאריכים, מה עשית ביום-יום?
3. מה את/ה הכי גאה בו מהתפקיד הזה? (ואז: "בכמה? למי? מה השתנה בזכותך?")
4. חזור/י על 2–3 לכל תפקיד קודם.
5. השכלה, צבא/שירות, הסמכות.
6. כלים, תוכנות, שפות.
7. משהו ייחודי — התנדבות, פרויקט צד, פרס.

אחרי כל תשובה — ניסוח מוצע + שאלת המשך לחידוד מספרים.
