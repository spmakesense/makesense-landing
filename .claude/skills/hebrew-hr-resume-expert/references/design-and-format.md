# עיצוב ופורמט קורות חיים

## עיקרון: יפה וגם קריא למכונה
עיצוב "מגזיני" עם שתי עמודות, אייקונים וגרפים של כישורים נראה טוב — ונכשל ב-ATS. ברירת המחדל היא **פריסה חד-עמודית נקייה**, עם היררכיה ברורה ומקסימום צבע אחד להדגשה.
גרסה "מעוצבת" (שתי עמודות, צבע, תמונה) — רק לתפקידי עיצוב/קריאייטיב, לשליחה ישירה לאדם ולא דרך מערכת, ותמיד בנוסף לגרסה נקייה.

## מפרט מומלץ

| רכיב | עברית | אנגלית |
|---|---|---|
| גופן | Heebo / Assistant / Rubik / Arial | Calibri / Inter / Arial / Georgia |
| שם | 20–26pt מודגש | 20–26pt |
| כותרות מקטעים | 12–14pt מודגש + קו דק | 12–14pt, CAPS אופציונלי |
| גוף | 10.5–11.5pt | 10–11pt |
| שוליים | 1.5–2 ס"מ | 0.5–0.8" |
| ריווח שורות | 1.1–1.2 | 1.0–1.15 |
| צבע | שחור/אפור כהה + צבע הדגשה אחד (כחול כהה / ירוק כהה) | זהה |
| יישור | לימין (RTL), תאריכים בצד שמאל | לשמאל, תאריכים בצד ימין |

## RTL — דגשים לקו"ח בעברית
- `dir="rtl"` / יישור לימין בכל המסמך; תבליטים בצד ימין.
- מונחים באנגלית בתוך שורה עברית — לבדוק שסוגריים ונקודות לא "קופצים" לצד הלא נכון.
- טלפון ומייל — כל אחד בשורה/מקטע משלו כדי שסדר התווים לא יתהפך.
- ב-HTML: CSS logical properties (`margin-inline-start`) — ראו סקיל `hebrew-rtl-best-practices`.

## פלטים אפשריים
- **Markdown / טקסט** — ברירת מחדל, להעתקה.
- **DOCX** — סקיל `docx` (הכי טוב ל-ATS). בעברית: להגדיר כיווניות RTL לפסקאות.
- **PDF** — סקיל `pdf` או HTML מודפס (Cmd/Ctrl+P ← Save as PDF).
- **HTML להדפסה** — עמוד A4 יחיד, `@page { size: A4; margin: 15mm; }`, Google Fonts (Heebo), בלי JS.
